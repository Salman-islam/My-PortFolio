# C# + Angular portfolio starters

Three independent repositories: TeamDesk (employees), Stockroom (inventory), and SupportFlow (support tickets). Each folder contains its own Angular frontend, C# API, README, sample HTTP requests, and screenshot. Extract one folder and upload its contents as a separate GitHub repository. Run only one project at a time on the default ports.

See each README for setup, connection flow, endpoint documentation, and scope. These are starter projects intended for learning and customization, not complete production systems.
